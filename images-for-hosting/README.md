# DSGN 110 — handout figures

Figures used in the DSGN 110 (Design Thinking) course handouts, University of Nebraska–Lincoln,
College of Architecture. Hosted here so Canvas pages can link to them: Canvas strips embedded
`data:` images but leaves absolute `https://` image links alone.

Served via jsDelivr:

```
https://cdn.jsdelivr.net/gh/<user>/<repo>@main/images-for-hosting/<folder>/<file>
```

Several figures are third-party material reproduced for teaching. Please do not reuse them without permission.
